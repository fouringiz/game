# Ultimate Tower Defense — паспорт проекта (точка восстановления v1.6)

> **Как использовать:** вставь этот документ первым сообщением в новый чат с Claude и добавь: «Продолжаем с раздела "Текущая повестка"». Всё из разделов «зафиксировано» считается решённым и не пересматривается без запроса пользователя.
> **Сопутствующие документы:** лор-библия в двух языках — `ultimate-td-lore-ru.md` / `ultimate-td-lore-en.md` (мир и история подробно; здесь — механики и краткий канон).

## 1. Роль и процесс

- Claude — соавтор-геймдизайнер. Режим: **мозговой штурм** (не прототип, не диздок).
- Язык общения: **русский**.
- **Имена собственные** подаются в формате **English (русский в скобках)**.
- Формат: Claude предлагает пакеты идей (жирное название + суть + геймплейный крючок + отсылки к Red Alert / «Звёздному десанту», где уместно). Пользователь по каждой решает: «зафиксируй / убери / развей». В конце ответа — **один** вопрос.
- Отклонённые идеи повторно не предлагать. Сложные конструкции объяснять просто, при необходимости — со схемой.
- **Протокол веток проекта**: паспорт и лор-библии лежат в базе знаний проекта — каждая ветка видит их автоматически. Ветки не видят историю сообщений друг друга; синхронизация только через паспорт: в конце сессии ветка выпускает новую версию, старый файл в базе знаний заменяется новым. Разрез веток — по темам повестки; **арсенал и мутации — всегда одна общая ветка** (гонка вооружений проектируется парами). Этот принцип действует и на будущие темы: связанные системы не разносить по веткам.

## 2. Жанр и рамки

- Классический tower defense: лабиринт, пути, волны.
- Сеттинг: sci-fi. Вдохновение: **Red Alert** (экономика, тон) и **«Звёздный десант»** (враг, сатира).
- Дизайн-цель «ультимативности»: игру нельзя «решить» одним билдом — всё построено вокруг принуждения к адаптации.
- **Закон дизайна «Путь свят»** (зафиксировано): лабиринт не игнорирует никто, включая летающих. Лор-обоснование: рой движется по феромонным магистралям — наземный поток метит тропу, и вся масса держится следа. Гарантия: планировка игрока и рельсовые стрелки никогда не обесцениваются.

## 3. Зафиксированные механики

### Экономика (внутри миссии)
- Кредиты — **только за убийства** (премии экспедиционного фонда за «биоматериал»). Добыча ресурсов — возможно в будущих обновлениях, на старте нет.
- **Единый пул энергии** (как в Red Alert): генераторы производят, башни потребляют; одна шкала «производство vs потребление», без проводов.
- **Мягкий отказ**: при дефиците башни стреляют ~на 40% медленнее, экран темнеет («браунаут»). Мгновенного проигрыша нет.
- **Пауза башни**: −70–85% потребления энергии; после снятия с паузы «прогрев» 2–3 сек до первого выстрела.
- Генераторы уязвимы — на них охотится каста Пиявок.

### Башни
- **Модульность**: шасси (турель / артплатформа / док дронов) + модуль оружия (плазма / рельсотрон / крио) + чип наведения (в т.ч. «приоритет: летающие», «приоритет: пиявки»). Переоснащение возможно посреди партии.
- **Ручные апгрейды («железо»)**: Mk I → Mk II → Mk III за кредиты; растут урон, дальность, тир модулей — и энергопотребление.
- **Ветеранство («экипаж»)**: только за убийства, не покупается. Ранги: обычная → ветеран → элита. Даёт скорострельность и крит; элита — уникальный перк оружия.
- Апгрейд железа **сохраняет** нашивки ветеранства.

### Информация
- Без радара виден состав **1 следующей волны**. Каждый уровень радара: +1 волна обзора. Радар ест энергию; браунаут роняет обзор до базового.
- Лор-обёртка: радар «читает инкубаторы» роя.
- **Отчёт после волны**: мутации врага в стиле военного рапорта + видимые визуальные изменения. Принцип: адаптация врага всегда читаема игроком.

### Супероружие
- Здание; заряжается на глазах игрока 3–4 волны.
- Скорость зарядки пропорциональна **профициту энергии**; заряжается только при положительном балансе.
- Один слот на партию, выбор в начале (билдообразующее решение):
  - **Орбитальный резак** — выжигает полосу поперёк лабиринта;
  - **Стазис-поле** — заморозка всех врагов ~8 сек;
  - **Нанитный рой** — заражение: помеченные при смерти взрываются и заражают соседей.

### Карта миссии
- **Рельсовые стрелки**: переключение пути врагов между маршрутами за энергию; каста Стрелочников может взламывать/блокировать их.
- **Трофейные точки** (руины предтеч): реставрация за кредиты — летит ремонтный дрон, длится ровно 1 волну, объект уязвим (враги бьют по пути, Литофаги целятся специально). Разрушен недострой → потеря 50% вложенного, начинать заново.
- Типы руин: **подстанция** (+25 энергии), **древняя турель** (фиксированное оружие предтеч, модули не сменить, ветеранство копит), **сенсорная мачта** (+1 волна обзора, работает даже без радара).

### Кампания и стратегическая карта — «Кольцо» (зафиксировано)
- **Форма**: радиальная сеть узлов — **врата** (база, точка прибытия) в центре, вокруг три кольца узлов (~15–18 узлов всего; цифры черновые). Узел = одна TD-партия. После взятия узла открываются соседние; движение изнутри наружу, маршрут выбирает игрок.
- **Типы узлов по фракциям**: *раскопы* (Наука — крохи сюжета и научные бонусы), *инфраструктура* (Корпорация — пассивы и ассигнования), *рубежи* (Военные — ослабляют/замедляют контратаки).
- **Кольца = акты**: чем дальше от врат, тем злее рой и мутации. (Черновая деталь: Матриарх — босс-экзамен шлюза акта II.)
- **Шлюзы**: между кольцами 3 обязательных сюжетных узла + финал. Только в них живёт раскрытие тайны предтеч (содержание — позже; слоты зафиксированы).
- **«Три подписи»** (зафиксировано): шлюз вскрывается только после закрытия в текущем кольце минимум по одному узлу **каждой** фракции. Лор/UI: приказ о вскрытии с тремя строками подписей — Sato, Hayes, Marsh подписывают по мере выполнения своих условий. Точные квоты (особенно акта III) — вопрос балансной сессии. Следствие: раш по «позвоночнику» карты невозможен; каждый акт игрок играет во все три типа миссий.
- **Сигнатура** — стратегическая шкала шума: растёт с каждым занятым узлом и реставрацией. По порогам рой **контратакует** — миссия обороны уже занятого узла. Рубежи военных ослабляют контратаки. «Три подписи» гарантируют рост сигнатуры — стелс-ран невозможен.
- **Лестница поражений**: провал наступления — узел не взят, сигнатура слегка подросла (шум боя), можно повторить или обойти; провал обороны при контратаке — узел потерян, его пассивы гаснут, **гарнизон погибает (ветераны — насовсем), восстановленные руины разрушены**, отбивать заново; потеря врат — **конец кампании**, единственный полный game over.
- **Победа**: финальный узел «Сердце» за третьим кольцом. Что там — решается при проработке предтеч (плейсхолдер зафиксирован).

### «Гарнизон» — что остаётся на узле (зафиксировано)
- При взятии узла игрок выбирает часть башен, которые остаются на нём **насовсем** — с Mk, модулями и нашивками ветеранства; остальное демонтируется. Башни между миссиями не переезжают. Лор: экипажей и энергии мало, всё лишнее — фронту (голосом Hayes: «Оставьте четверых. Остальное — на передовую»).
- **Размер**: ~30% построенных башен (ЧЕРНОВИК). Альтернатива — плоское число (3–4). Трейдофф «% масштабируется с богатством узла vs плоское число предсказуемее» — сравнить на балансной сессии.
- **Интел при выборе гарнизона** (выбор — не гадание): (1) *профиль сектора* — местная популяция роя по каталогу Marsh видна на экране выбора; контратакует местный рой; (2) при подходе сигнатуры к порогу Hayes присылает **сводку с превью состава** контратаки; (3) в начале обороны модули гарнизонных башен можно **переоснастить** за кредиты — шасси, Mk и ветеранство сохраняются. Принцип: гарнизон — фора, а не вся оборона; наказываются моно-гарнизоны, а не «неугаданное будущее».
- **Драматургия обороны**: та же карта, которую игрок когда-то брал, с его гарнизоном и руинами; гарнизон законсервирован — старт с сиреной и **прогревом 2–3 сек** при уже видимой первой волне; рой заходит **с дикой стороны** (не оттуда, откуда заходил игрок), цель — ядро узла; дальше полноценная партия: стройка, кредиты за убийства, супероружие выбирается заново.
- **Реставрации вечны**: восстановленные руины — инфраструктура узла, не гарнизон; сохраняются всегда. Реставрация = инвестиция в будущие обороны узла.
- «+1 слот гарнизона» — кандидат военной ветки ассигнований (проходит фильтры: частая боль, дилемма жива, аддитивен).

### Кампанийные апгрейды — «ассигнования» (ЧЕРНОВИК: концепция одобрена, узлы и цифры не зафиксированы)
- Действуют **между этапами на стратегической карте**, не между волнами внутри миссии.
- Валюта: **ассигнования** — начисляются за пройденные этапы + бонусы за опциональные цели миссий.
- **Общий пул, три ветки**: Командование / Научный корпус / Корпорация. На всё не хватает → идентичность прохождения и реиграбельность.
- **Правило**: апгрейды — только пассивы; ноль новых внутримиссионных сущностей и кнопок.
- Подача: каждый купленный апгрейд приходит документом в голосе фракции (приказ / меморандум / подписанная смета) — канал сатиры и характеров.
- ⚠️ Деревья проектируются отдельной балансной сессией. Предложенная методика (ждёт утверждения):
  - Правила-предохранители: (1) ослаблять боль, не удалять дилемму — у каждой механики несгораемый минимум напряжения (браунаут никогда не 0%); (2) аддитивность вместо мультипликативности; (3) нет must-have — обязательный для всех узел вшивается в базу; (4) ситуативность легальна, бесполезность нет — узкий узел требует контентной гарантии; (5) ветки на ортогональных осях: мощь в моменте / информация и адаптация / темп и экономика; (6) дефицит как балансир — ассигнований хватает на ~60–70% одной ветки (черновая цифра).
  - 5-вопросный фильтр для каждого узла: какую боль лечит? как часто болит? с кем конкурирует? стак-тест всей ветки? какую дилемму задевает и выживает ли она?
  - Числа на бумаге не балансируются: фиксируем роли и потолки («не сильнее чем»), настройка — плейтестами.
- Черновые примеры направлений (ничего из списка не зафиксировано):
  - *Командование*: стартовый гарнизон (бесплатная башня или стартовые кредиты), «+1 слот гарнизона», предзаряд супероружия (этап начинается с 25% шкалы), ускоренный прогрев после паузы, смягчённый браунаут (−40% → −25%), ускоренное ветеранство.
  - *Научный корпус*: +1 волна обзора радара, подсветка Координатора до выхода волны, удешевлённое переоснащение модулей, усиленные эффекты руин, «прикладная ксенология» — новые мутации роя вступают в силу на волну позже.
  - *Корпорация* (экономика и всё смежное): +% гонорара за биоматериал, ускоренная/удешевлённая реставрация руин, страховка недостроя (возврат 75% вместо 50%), стартовый капитал, оптовые контракты на реакторы (+5 энергии с генератора).

## 4. Отклонено (не предлагать снова)

- Передислокация башен (MCV-стиль).
- Овердрайв / перезаряд супероружия до 150%.
- Причина «Земля умирает» в лоре.
- Добыча ресурсов на старте (отложена в будущие обновления).
- Падальщики (каста, жрущая трупы на тропе).
- Перекормленная пиявка с микро-ЭМИ при смерти.
- Возврат энергии при убийстве пиявки.
- Аэрозоль (споровый туманник, слепящий радар).
- Летуны, игнорирующие лабиринт (нарушает закон «Путь свят»).
- Эмоциональный стержень-слоган «мы это разбудили — нам и держать» (претенциозно; факты канона остаются, лозунга нет).
- Титул игрока «УОК / Оператор».
- Полное сохранение всей обороны узла между миссиями и полный сброс обороны узла (обе крайности; принят «Гарнизон»).

## 5. Враг — «Голод» (имя зафиксировано)

Суть (ДНК: Лиенсу + «Звёздный десант»): биологический рой, **направляющий собственную эволюцию**. Оружие — сама жизнь: инкубаторы-фабрики плоти, чудовищная скорость размножения, посредственные технологии, безупречное производство пищи. Потерянная армия — «временный дефицит биомассы». Настроение: «Это был не флот. Это был первый укус».

- Имя: **«Голод»** (сленг экспедиции, финально). Официальное в каталоге: «Консументы» (рабочее).
- Симметрия экономик: **обе стороны питаются смертью** — мы получаем кредиты с их трупов, они биомассу с любых.

### Архитектура ростера (зафиксировано)
- **Касты — роли, мутации — модификаторы**: каста задаёт тело и поведение, направленная эволюция навешивает мутации-контрмеры. Игрок узнаёт силуэт, но видит изменения.
- **На каждую систему игрока — орган роя**: огневая мощь → масса/броня/реген; энергия → Пиявки; лабиринт → Стрелочник; реставрация → Литофаг; сама эволюция → Координатор.
- **Двойные имена**: официальное (каталог экспедиции) + окопный сленг. Бестиарий оформлен как **прейскурант**: у каждой касты категория выплаты — канал сатиры.

### Стартовый ростер каст (зафиксирован)
- **Фуражир** («саранча», кат. E): базовое тело, река плоти; перепрофилированные сборщики пищи. Проверяет суммарный DPS игрока.
- **Панцирник** («трамвай», кат. C): медленная живая стена; мелочь в его «тени» прикрыта от настильного огня. Контригра: навесной огонь; крио по нему одному выгоняет стадо из тени.
- **Санитар** («мамка», кат. B): феромонная аура регенерации в середине потока. Цель для чипа приоритета.
- **Аэропланктон** («мошкара», кат. E): летит **вдоль тропы**, низко, по феромонному следу (закон «Путь свят»). Быстрые, хрупкие, тучей. Навесное оружие по воздуху не бьёт → наказывает моно-артиллерию. Симметрия: Панцирник наказывает настильный огонь, Аэропланктон — навесной.
- **Пиявка** (кат. B): электротроф; присасывается к генераторам; «Пир» (бафф всем врагам на поле, пока кормится, стак до ~3) и «Сытые волны» (украденное усиливает будущие волны). Выпитое уходит в улей безвозвратно.
- **Стрелочник** (офиц. «Нейрокоплер», кат. B): присасывается к рельсовой стрелке, перещёлкивает или блокирует. Сеть предтеч для роя — родной язык. Наказывает единственный «идеальный маршрут».
- **Литофаг** («сносчик», кат. C): кислотный разрушитель; целенаправленно атакует реставрируемые руины. Ремонт при нём — эскорт-миссия.
- **Координатор** (кат. A, максимальная выплата): наблюдатель; доживёт до конца волны → следующая адаптация ×2; убит → эволюция этой волны «ослепла».
- Босс **Матриарх** («Мать»): шагающий инкубатор — рожает Фуражиров на ходу; волна не кончается, пока она идёт. Экзамен на burst и тайминг супероружия.

### Мутации (слой поверх каст; полный каталог — отдельной сессией вместе с арсеналом)
- **Ороговение**: −30% урона от кинетики.
- **Зеркальный хитин**: −30% урона от плазмы.
- **Гликолевая кровь**: крио-эффекты вдвое короче.
- **Рассредоточение**: держат дистанцию — анти-сплеш поведение.
- **Обходной инстинкт**: предпочитают маршрут мимо максимальной плотности огня — играют против стрелок игрока.

## 6. Лор (канон, кратко — подробно в лор-библии)

- **Находка**: обломки на дне Тихого океана → целый корабль во льдах Европы → столетие расшифровки → единственный прыжок к маяку предтеч.
- **Предтечи**: исчезли миллионы лет назад; разгадка раскрывается постепенно по кампании (не прорабатывать без запроса). Слоты раскрытия: три шлюза + финал «Сердце».
- **Вены планеты**: дремлющая планетарная энергосеть предтеч, проросшая роем; инкубаторы подключены к ней — улей «везде под нами».
- **Почему не улететь**: (1) двигатель выгорел, перезарядка десятилетиями, прыжки только между маяками; (2) след прыжка приведёт рой к Земле — колония-брандмауэр; (3) здесь наследие предтеч.
- Мы — **экспедиция**, не беженцы; Земля цветёт и не знает. Связь односторонняя; брифинги — «письма домой».
- Рой охотится на энергосигнатуры предтеч; возможно, наш прыжок разбудил улей.
- **Название экспедиции**: пока просто «Экспедиция». Кандидат **The Bell (Колокол)** паркован до сессии интерфейсных текстов.

### Структура экспедиции — «трёхглавая» (Вариант В, зафиксировано)
Три учредителя с несовместимыми уставами; каждая механика канона получает владельца:
1. **Корпорация-спонсор**: век финансировала расшифровку; владеет фондом премий и прейскурантом-бестиарием. Хочет окупаемости: артефакты, патенты, отчётность.
2. **Военное командование**: держит оборону; владеет орбитальной пушкой (супероружием). Хочет выжить и законсервировать угрозу: не копать, не шуметь.
3. **Научный корпус**: единственные, кто читает предтеч; ведут каталог «Консументы» и радарную разведку. Хотят копать глубже — а глубже значит громче сигнатура.
- Конфликт «наука копает — военные глушат» уже живёт в механиках (реставрация руин, сигнатура, семечко-«скважина») и служит двигателем постепенного раскрытия предтеч.
- **Правило**: фракции — фон, голоса и ветки ассигнований, а не менеджмент для игрока. Никаких очков репутации на старте.

### Лица фракций (зафиксировано; ранние рабочие имена Ланге/Восс/Реми упразднены кастингом)
- **Evelyn Sato (Эвелин Сато)** — Корпорация, «директор по реализации активов» (активы — трупы роя и руины предтеч). Внешность: азиатка. Характер: полированная безжалостность; искренне верит, что отчётность — способ пережить апокалипсис. Манера: страдательный залог («было принято решение»), сноски мелким шрифтом, каждое сообщение заканчивается дисклеймером. Владеет в UI: все деньги — квитанции за биоматериал, премии, счета реставрации, страховки недостроев, корпоративная ветка ассигнований.
- **Colonel M. Hayes (полковник М. Хейз)** — Командование. Внешность: чернокожий; имени никто не знает, в документах — инициал. Характер: устал, считает всё — людей, ватты, секунды; руинам предтеч не доверяет принципиально. Манера: рубленые сводки без прилагательных, всё пронумеровано; эмоция читается только в длине паузы между строками. Владеет: боевые предупреждения («РОЙ ПИРУЕТ ×N», пиявка на генераторе, взлом стрелки), сводки о контратаках и профили секторов, санкция супероружия («Орудие ваше. Не промахнитесь»), итоговые сводки миссий, военная ветка.
- **Dr. Gideon Marsh (доктор Гидеон Марш)** — Научный корпус, глава ксенологии. Внешность: лысый, очки, седина по бокам головы. Характер: восторг и ужас разом; единственный, кто говорит с Командующим как с человеком. Манера: слишком длинные меморандумы, латынь, зачёркнутые слова, вечные P.S. и P.P.S. («P.P.S. Прошу вернуть мой спектрометр»). Владеет: инкубаторные прогнозы радара, рапорты о мутациях, каталог «Консументы» и профили популяций секторов, записки о руинах и предтечах — канал постепенного раскрытия тайны.

### Игрок (зафиксировано)
- Титул: **Commander (Командующий)** — дань Red Alert. Все трое обращаются «Commander», каждый со своей интонацией: у Sato — как строка договора, у Hayes — как звание, у Marsh — как обращение к единственному взрослому.
- Лор должности: пост создан как четвёртая, нейтральная точка — ни одна фракция не согласилась подчинить оборону другой. Командующему пишут, а не приказывают; сметы ассигнований приходят на его стол; контракты фракций опциональны. «Три подписи» шлюзов — продолжение того же устройства.
- Протагонист молчалив; его характер читается по документам, которые он подписывает.

## 7. Тон (зафиксировано)

- Бои серьёзные, обёртка сатирическая (Red Alert + Starship Troopers): прейскурант-бестиарий, квитанции за биоматериал, пропагандистские ролики между миссиями, документы трёх фракций как канал характеров. Юмор дозированно.
- **Совместные документы как комедия трения**: бестиарий-прейскурант пишут втроём — описание вида (Marsh, латынь и восхищение), цена за голову (Sato, сноска про налоги), резолюция поперёк страницы (Hayes: «Огонь на поражение»). Приказ о вскрытии шлюза с тремя подписями — из той же серии.
- Пропагандистские ролики «Хотите узнать больше?» — продукт отдела внутренних коммуникаций Sato **для собственных сотрудников** (Земля о рое не знает): корпоративный мотивационный контент посреди осады.

## 8. Отложено на будущее / идеи-семена (не фиксировано)

- **Босс «Прорыв»** («гейзер»): титан вырывается из узла вены посреди лабиринта. Берётся **только вместе** с фичей «видимые узлы вен». Статус: будущие боссы.
- Руина-«скважина»: энергия игроку, но сигнатура громче → волны злеют.
- Карты с видимыми венами — средовое повествование (связано с Прорывом).
- Опциональные цели миссий как **контракты фракций** — источник ассигнований с характером.
- Название **The Bell (Колокол)** — примерить на бланках в сессии интерфейсных текстов.
- «Письма домой» на стыках актов (черновое размещение).
- Добыча ресурсов — будущие обновления.

## 9. Текущая повестка (продолжать отсюда)

1. Арсенал башен + полный каталог мутаций (одной сессией, как гонка вооружений).
2. Балансная сессия: деревья ассигнований + цифры кампании (размер колец, квоты «Трёх подписей», пороги сигнатуры, размер гарнизона: ~30% vs плоское число) — сначала утвердить методику.
3. Сессия интерфейсных текстов: бланки, квитанции, рапорты трёх голосов; там же — судьба названия «The Bell (Колокол)».
4. Будущие боссы (Прорыв + узлы вен) — по желанию.
5. Предтечи — только постепенное раскрытие, прорабатывать позже.
